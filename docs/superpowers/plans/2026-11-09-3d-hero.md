# 3D Bestseller Hero, Premium Polish and Vercel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put Soft Dove in the hero as a fast, real-time 3D bottle with
"Add 50 ml" in the hero, polish the rest of the page (card tilt, section
order), and ship the site to Vercel as a public demo hidden from search engines.

**Architecture:**

- The hero stays a Server Component that paints the existing SVG `Bottle`.
- A small client leaf decides with a pure, tested policy whether this device
  gets 3D. If yes, it lazy-loads a React Three Fiber scene after first paint
  and fades the canvas in over the SVG, at the same size.
- The scene renders only while the hero is on-screen and the tab is visible.
- Everything else stays static. Deploys use the Vercel CLI from this machine.

**Tech Stack:**

- Next.js 16.4.5, React 19.3.1, TypeScript strict, Tailwind v4.
- three 0.187.0, @react-three/fiber 9.8.2 (its peer range is react
  `>=19 <19.4`, which is compatible), @react-three/drei 10.7.9, @types/three 0.187.0.
- @vercel/speed-insights 2.1.0; the vercel CLI 65.12.1 via `npx`.

**Spec:** `docs/superpowers/specs/2026-11-09-3d-hero-design.md` (read it first)

## Global Constraints

**Performance:**

- Lighthouse mobile performance of at least 90 on `/` (production build).
- LCP under 2.5 s, CLS under 0.05, INP under 200 ms.
- 3D code at most 300 KB gzipped. It is not in `/`'s initial JS, and no
  other route loads it.
- The render loop stops when the hero is off-screen or `document.hidden`.

**Fallback (SVG bottle, no WebGL canvas) when:**

- `prefers-reduced-motion: reduce`
- no WebGL, or the context fails or is lost
- `saveData`
- `effectiveType` of `slow-2g`, `2g` or `3g`
- `hardwareConcurrency <= 4` **and** `deviceMemory <= 4`, where both are known

**Layout and page structure:**

- The SVG bottle is the first paint, and the canvas covers exactly its box,
  so there is zero layout shift.
- Hero `h1` stays "Perfume that stays with you.", and "Magic Perfumery" is
  the top eyebrow.
- Soft Dove block: eyebrow "Our bestseller", the name as `h2`, the tagline,
  the button "Add 50 ml — ₹599" (adds to the bag and opens it), and the
  link "Shop all perfumes".
- The featured perfume is the slug `soft-dove`, read through `src/lib/catalog.ts`.
  Never hard-code it in components.
- Home section order:
  1. hero
  2. trust strip
  3. shop for
  4. all perfumes
  5. occasions
  6. gift guide
  7. real bottles
  8. how ordering works
- The announcement bar and the floating WhatsApp button are unchanged.
- No "bestseller" badges on cards; "Our bestseller" appears only in the hero.

**Rules from `AGENTS.md`:**

- Server Components by default.
- Data comes through `catalog.ts`, env through `env.ts`, and money through
  `formatPrice`.
- The brand name comes from `siteConfig`.
- Exact pinned versions.
- "Bag", never "cart", in UI copy.

**Premium feel (the user's emphasis):**

- Motion uses `--ease-magic`.
- Every feature (bag, quick add, filters, WhatsApp) stays one tap away.
- Visual review screenshots are required on each UI task.

**Deployment:**

- The site is indexable only when `NEXT_PUBLIC_ALLOW_INDEXING=true`.
  The default is off, which means `noindex, nofollow` and robots disallow all.
- Git: `main` holds the baseline commit, and the work happens on the branch
  `feat/3d-hero`.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **WebGL context lost** mid-session, for example on a GPU reset or when a
   mobile tab is backgrounded. Expected: the canvas is removed and the SVG
   bottle shows again, with no blank hero. _Pinned by: Task 3, Step 1
   (`onContextLost` → fallback test)._
2. **Pressing "Add 50 ml" twice in the hero.** Expected: one Soft Dove 50 ml
   line with qty 2, and the bag reads "Open bag, 2 items". _Pinned by:
   Task 4, e2e step._
3. **Phone rotation or window resize** while the 3D is running. Expected: the
   canvas follows the SVG box, with no overflow and no layout shift. _Pinned
   by: Task 4, e2e 320/360px plus resize check._
4. **JavaScript disabled or slow.** Expected: the hero still shows the Soft
   Dove SVG, the text, and the "Shop all perfumes" link. _Pinned by: Task 4,
   e2e with `javaScriptEnabled: false`._
5. **Low-power and Save-Data devices.** Expected: no WebGL canvas and no
   three.js download. _Pinned by: Task 1 unit tests, plus the Task 6 e2e
   with reduced motion._

### Task 3: The 3D scene, lazy-loaded with an SVG-first fallback

**Files:**

- Modify: `package.json`. Add exact versions: `three@0.187.0`,
  `@react-three/fiber@9.8.2`, `@react-three/drei@10.7.9`, and dev
  `@types/three@0.187.0`.
- Create: `src/components/home/hero-3d/bottle-model.tsx`, the meshes only.
- Create: `src/components/home/hero-3d/hero-scene.tsx`. This is the
  `Canvas`, lights, shadow and motion; it is the default export, for `next/dynamic`.
- Create: `src/components/home/hero-3d/hero-bottle.tsx`, a `"use client"`
  wrapper that applies the policy, lazy-loads the scene, handles visibility
  and fades it in.
- Test: `tests/unit/hero-motion.test.ts`

**Interfaces:**

- Consumes:
  - `shouldUse3D` and `readDeviceSignals` (Task 1)
  - `labelSvg` and `LABEL_ASPECT` (Task 2)
  - the `Fragrance` type
- Produces:
  - `HeroBottle({ fragrance, children }: { fragrance: Fragrance; children: React.ReactNode })`.
    `children` is the SVG `Bottle` for first paint and fallback. It renders
    a `relative` box. The children stay in the flow; the canvas is absolutely
    positioned at `inset-0` above them and fades in over 600 ms once its
    first frame renders. The SVG is then hidden with `opacity-0`, not
    unmounted, so the box size never changes.
  - `hero-motion.ts`, a pure function:
    `bottleRotation(t: number, scroll01: number, pointer: {x: number; y: number}): {x: number; y: number}`.
    - y = idle turn `t * 0.35` + `scroll01 * Math.PI` + `pointer.x * 0.25`
    - x = `pointer.y * 0.12`
    - Inputs are clamped: `scroll01` to [0, 1] and `pointer` to [-1, 1].

**Scene decisions (values the spec pins or the builder must not re-decide):**

- **Geometry** in scene units, with the bottle 2 units tall. Proportions
  follow `bottle.tsx`'s viewBox `0 0 60 200`, so 1 unit = 100 viewBox units:
  - body: a radius 0.24 cylinder, rounded with `RoundedBox`-style bevels or
    a lathe profile
  - label band: a separate open cylinder at radius 0.2405, height 0.92,
    with the texture
  - collar: white, radius 0.16
  - actuator: white, radius 0.09
  - overcap: a clear cylinder, radius 0.22
- **Materials:**
  - body: `MeshPhysicalMaterial` with `transmission 0.6, roughness 0.45,
thickness 0.3, color #f4f1f7`
  - overcap: `transmission 0.95, roughness 0.08`
  - white parts: `MeshStandardMaterial roughness 0.35`
- **Texture:** render `labelSvg` to a 1024×512 canvas via `Image` plus
  `drawImage`, then use it as a `THREE.CanvasTexture` with
  `colorSpace = SRGBColorSpace`, wrapped once around the band.
- **Lighting:**
  - drei `<Environment resolution={64}>` built only from `<Lightformer>`
    children, with no HDR file download
  - drei `<ContactShadows opacity={0.35} blur={2.5}>`
- **Renderer:**
  - `dpr={[1, 1.75]}`
  - `gl={{ antialias: true, powerPreference: "high-performance", alpha: true }}`
  - Use drei `<PerformanceMonitor>` to drop dpr to 1 on decline.
- **Frame loop:** `frameloop` is `"always"` only while an
  IntersectionObserver reports the hero box visible **and**
  `!document.hidden`. Otherwise it's `"never"`.
- **Entrance:** the bottle rises 0.3 units and settles over about 1.2 s
  using `--ease-magic`'s curve (cubic-bezier 0.2, 0.7, 0.1, 1).
- **Pointer lean:** only when `matchMedia("(pointer: fine)")` matches.
  Smooth it with `THREE.MathUtils.damp`.
- **Loading the scene:**
  - `next/dynamic(() => import("./hero-scene"), { ssr: false })`.
  - Mount it only after `shouldUse3D(readDeviceSignals())` and after
    `requestIdleCallback`, or `setTimeout(…, 200)` where that isn't available.
- **Losing the context:** listen for the canvas's `webglcontextlost` and for
  `onCreated` errors (wrap the scene in an error boundary). Either one sets
  state that unmounts the canvas and shows the SVG again.
- **Accessibility:** the canvas and wrapper are `aria-hidden`.
